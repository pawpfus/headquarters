# HEADQUARTERS

Markas komando 8-bit — landing page seluruh tools dalam satu ruangan pixel-art,
dengan dinosaurus ungu yang bisa berjalan mengunjungi tiap meja kerja.

**Live:** https://pawpfus.github.io/headquarters/

## Tools yang terhubung

| Stasiun | Tujuan |
|---|---|
| LAPORAN HARIAN V2 | https://hari-hari-laporan-v2.vercel.app/ |
| EVIDEN LCS | https://pawpfus.github.io/eviden_lcs/ |
| LAPORAN DISEMINASI | https://pawpfus.github.io/laporan-diseminasi/ |
| LAPORAN KSA | https://pawpfus.github.io/laporan-ksa-2026/ |
| SKP FORGE | https://pawpfus.github.io/skp-forge/ |

## Kontrol

- **Panah / WASD** — berjalan (D-pad muncul otomatis di layar sentuh)
- **Ketuk/klik meja** — karakter mencari jalan sendiri ke meja itu
- **ENTER / tombol BUKA** — membuka tool saat berada di dekat meja
- **M / tombol MENU** — daftar akses cepat semua tools

Satu file `index.html` tanpa dependensi build; semua link tools ada di
konfigurasi `TOOLS` di bagian atas skrip.
